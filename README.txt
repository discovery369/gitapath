GitaPath – Telugu Translation Batch v20

This package continues from v19 and adds revised Telugu translations for Bhagavad-gita 17.1–17.28.
Grouped source passages 17.5–17.6 use the same translation. Existing Sanskrit corrections, favourites, read/unread controls, notes and attachments are retained.

Coverage note: This batch revises chapter 17 only. It does not claim that all Telugu translations have been scholar-reviewed. Machine-assisted Telugu should be reviewed by a fluent Telugu reader and a Sanskrit/Gita scholar.

Install: replace index.html and sw.js in the GitHub Pages repository root, commit to main, then reopen the app online to refresh the service worker.

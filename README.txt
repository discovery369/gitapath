GitaPath v22 — Telugu Translation Batch
Chapter 18, verses 18.29–18.50

This package continues the Telugu translation work from v21.
- Adds Telugu translation drafts for 18.29–18.50.
- Verses 18.36 and 18.37 share the same grouped source passage and therefore have matching Telugu text.
- Preserves the existing Sanskrit text, transliteration system, English fallback, UI, favourites, notes, attachments, and read/unread features.
- Updates the offline service-worker cache to v22.

The Telugu text is machine-assisted draft translation. It has not been certified by a Sanskrit or Telugu scholar; please have it reviewed before treating it as a definitive edition.

To update GitHub Pages:
1. Extract this ZIP.
2. Replace index.html and sw.js in the repository root.
3. Commit and push to the main branch.
4. Open the website online once, then close and reopen the installed PWA.
